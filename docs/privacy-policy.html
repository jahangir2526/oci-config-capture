Privacy Policy for OCI Config Capture

OCI Config Capture runs entirely in the user's browser and does not collect, sell, share, or transmit personal information, browsing history, or user data to any external server or third party.

The extension reads the active Oracle Cloud Infrastructure Console tab only when the user clicks the Capture button. Any captured configuration details are shown locally in the extension popup.

Any configuration or state saved by the extension is stored locally on the user's device using Chrome extension storage. This local data is used only to support extension functionality and is not sent outside the browser.

The extension does not use analytics, tracking, advertising, or remote logging.
